I also build internal tooling for the brand — acquisition engine, funding bot, influencer-discovery agent, command center, ops dashboard. Most run as private repos; the strategic layer is part of the edge.

## How I actually build

I don't write Python by hand. I work through AI agents — Claude Code, Cursor, OpenHands. They write the code; I direct.

I write specifications and the agents ship. When something breaks, I learn what broke and tighten the spec. The compounding artifact is the spec, not the code — which gets rewritten freely.

The model is fast — but only if your specs don't fall apart when the agent reads them. Most founders trying this fail because their specs aren't tight. Mine are.
